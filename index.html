Guías de química (RUMBO CIENCIAS)

Cada guía tiene su propio panel de preguntas (sección #admin). Aquí controlas si aparece como publicada en el catálogo.

Cómo editar preguntas: entra a “Editor de preguntas” de la guía. Los cambios se guardan en localStorage de este navegador (no se sincronizan entre dispositivos). Usa la opción de exportar JSON dentro de cada guía para respaldar el banco.

Agregar una guía nueva: por ahora se hace copiando un HTML a la carpeta ciencias/ y registrándola en este panel (campo de abajo). En una versión con servidor se conectará a base de datos.

Registrar guía nueva (local)

Añade una entrada al catálogo local. Debe existir el archivo HTML en ciencias/.
